# CorkDeck 游戏实测

按游戏名称或 Steam AppID 查询。[公共查询页](https://lerosua.github.io/CorkDeck/compat/) · [GitHub 可搜索列表](reports.tsv) · [中文上报表单](https://github.com/lerosua/CorkDeck/issues/new?template=compatibility.yml)

网页版和 Switch 共用 reports.tsv。每行记录一次实测，设置、版本或结果不同可以并存。维护者核对 Issue 后，将报告填入列表的一行，并将「来源」设为该 Issue 的永久链接。同一玩家对同一版本和设置的更正应更新原行。历史记录保留原文出处，未记载的版本或设置写「未记录」。

表格为 UTF-8，字段之间使用制表符，字段内使用单行纯文本。实测结果取「启动失败」「仅到启动流程」「游戏中遇阻」「可持续游玩」「已通关」之一。简要说明控制在 240 个 UTF-8 字节内，记录实际卡点或游玩时长，详细过程放在来源中。下载或安装错误请走故障报告入口。
